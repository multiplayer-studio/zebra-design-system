## Subtle

Use subtle for context and guidance. It informs without interrupting, and several can share a page.

<Canvas of={InPageBanner.Subtle} />

## Solid

Use solid for the one message on a view that blocks or changes what the person can do. The actions and the dismiss draw light on every fill.

<Canvas of={InPageBanner.Solid} />

## Shape

`rounded` sets the corners, and the banner passes the same shape to its actions and dismiss.

<Canvas of={InPageBanner.Shape} />

## Narrow

The text keeps a minimum width. When the container is narrower, the actions wrap beneath the text.
