## This is a testing kit

You're helping test the Zebra Design System. As you build, Claude notes every problem with the design system itself (a wrong colour, a missing component, docs that don't add up) in `CHANGES.md` in the kit folder. You can point problems out too: *"The tabs look wrong."*

When Claude finishes what you asked, it says something like **"Filing 2 kit bugs to Jira: …"** and creates a ticket for each one for the design-system team. To skip one, just say so: *"Don't file the second one."* Jira needs to be connected for this; if it isn't, Claude explains how and files the tickets later.
