## This is a testing kit

You're helping test the Zebra Design System, and in this kit you can change it. If something in the system is wrong or missing (a colour, a size, a component, a rule), ask Claude to change the design-system docs: *"Make the large button 56px tall"* or *"Add a warning variant to the banner."* Claude may also spot a problem and suggest a change; say yes or no.

Claude updates the docs, refreshes your prototypes so you can see the change, and notes each change in `CHANGES.md` in the kit folder. When it finishes what you asked, it pops up a question listing the changes and asks whether to send them to Jira. Untick any you don't want sent. Claude creates a ticket for each one you keep, so the design-system team can add it to the real system. Jira needs to be connected for this; if it isn't, Claude explains how and sends the tickets later.
